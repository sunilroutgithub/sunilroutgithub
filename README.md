## ⭐ Featured Project: ClinicOps AI

![tests](https://github.com/sunilroutgithub/clinicops-ai/actions/workflows/tests.yml/badge.svg)

An AI assistant for small-clinic admin work. It classifies patient messages, proposes appointment slots from requests like "Thursday afternoon", and extracts fields from insurance PDFs. **Emergencies, low-confidence results, incomplete documents and API errors go to a human review queue, and every action is audit-logged.** It does not diagnose or give medical advice, and it uses synthetic data only.

<div align="center">
  <img src="https://raw.githubusercontent.com/sunilroutgithub/clinicops-ai/main/docs/ui-review-queue.png" width="75%" alt="ClinicOps AI review queue" />
</div>

- **Evaluated, not just demoed:** 28/28 on a standard 28-message set and 14/15 on a harder 15-message set; all 7 emergency messages were routed to a human (small synthetic sets, results and limits are in the README)
- **Engineering:** FastAPI, SQLAlchemy, Gemini structured output, 8 automated tests, GitHub Actions CI, login and a daily AI request cap
- **Links:** [Code](https://github.com/sunilroutgithub/clinicops-ai) · [Live demo (login required, contact me for access)](https://clinicops-ai.onrender.com/ui)
